NAS Backup rclone

A personal backup and restore application operated by GitHub user jjyong916-spec. It uses rclone on a privately operated computer to copy files between an authorized Synology NAS and Google Drive.

Purpose and Google Drive access

The operator authorizes their own Google accounts to upload NAS backups to a designated Drive folder and later download them to restore the NAS. The application reads file names, folder structure, sizes and other metadata to find and compare files, and reads or writes file contents for these transfers.

The configured OAuth permission is full Google Drive access. This permission is broader than the backup workflow; the scripts are configured to use copy operations and skip existing files, without deleting source or destination files. This is a private utility, not a public sign-in or file hosting service.

Privacy

This website contains information only. It does not collect Google credentials, OAuth tokens or backup files. Please read the Privacy Policy for details about data use, storage and revoking access.
