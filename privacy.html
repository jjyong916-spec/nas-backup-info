NAS Backup rclone

Privacy Policy

Effective date: October 5, 2026. Operator: jjyong916-spec. This policy describes the personal NAS Backup rclone utility and this informational website.

Data accessed and purpose

With the account holder's authorization, the utility accesses Google Drive files and folder metadata (including names, IDs, paths, sizes, timestamps and available checksums), file contents, and account information needed to identify the authorized account and its storage capacity. These are used only to back up NAS files to Google Drive, inspect or compare backups, and restore files from Drive to the NAS. Full Drive OAuth access is requested by the configured client; the backup scripts use copy operations without deleting source or destination files.

Storage and sharing

Backup files are stored in the operator-selected Google Drive folder; restored files are stored on the operator-selected local or NAS destination. Access follows the permissions configured by the operator on those locations. OAuth tokens and client configuration are stored locally on the operator's computer. Operational logs may contain file names, paths, timestamps and error details. The utility does not sell data, use it for advertising, or use it to train AI models. It has no separate public application server or third-party analytics.

Retention and control

Copies, logs and local authorization configuration remain until the operator removes them. Revoking authorization stops future authorized access but does not remove existing backup copies. Access can be revoked in Google Account settings under third-party connections. The operator can separately remove local authorization files and manage backup files through Google Drive or the NAS. The backup workflow does not automatically delete files.

Website and security

This static website does not request account sign-in or collect backup files or tokens. GitHub Pages may process technical request information under GitHub's privacy policy. Google API transfers use HTTPS. Local files and credentials are protected by the operator's device and account access controls; no system is guaranteed risk-free.

Google API data

NAS Backup rclone's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and updates

For questions, contact the operator through the project issue tracker. Do not submit private files, credentials or tokens in public issues. Updates to this policy will be published here with an updated effective date.
